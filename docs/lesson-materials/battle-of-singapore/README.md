# Battle of Singapore: starter materials

Prepared on 28 October 2026 for a first generation using the existing platform. No application code or saved adventure was changed.

## Use

1. Create a new adventure.
2. Add the six numbered `.txt` files as six separate sources. The source input accepts `.txt` files. Alternatively, paste each file separately.
3. Paste the content under “Brief to paste” in `generation-brief.md` into the creation conversation. Keep the brief separate from the historical source uploads.
4. Start with the supplied sources; add outside sources only where the teacher can identify a specific gap.
5. At review, check the source labels, chronological boundaries, essential conversations and evidence dependencies before publishing.

The source texts are short prepared adaptations, not downloads of full original articles. The two quoted civilian extracts and one diary extract are identified individually. They were verified against the institutional publications that reproduce them, not against full recordings or the original diary.

| File | Contribution |

## Maps and fuller originals

- [1942 military map of Singapore, AWM2023.10.15](https://www.awm.gov.au/collection/C3416695). The catalogue identifies Eastern Command's Intelligence Section as creator and a handwritten April 1942 annotation. This is a retrospective map of the February attack and Australian positions at surrender, not a map a character possessed before the landings. [Original two-page scan](https://s3-ap-southeast-2.amazonaws.com/awm-media/collection/AWM2023.10.15/bundled/AWM2023.10.15.pdf). The scan has no extractable text in the browser tool; use it as a visual reference rather than relying on it as the only generation input.
- [Malayan campaign map, Department of Veterans' Affairs](https://anzacportal.dva.gov.au/resources/map-malaya). Useful for the peninsula-wide orientation before the island battle; do not present it as a wartime document without establishing its production date.
- [Farrell's full scholarly paper](https://www.nids.mod.go.jp/publication/senshi/pdf/201603/09.pdf). Optional teacher background; the source adaptation only summarises its opening argument. This paper is by a historian and hosted by Japan's National Institute for Defense Studies; it is not a Japanese eyewitness account.
- [National Archives' Fall of Singapore exhibition](https://corporate.nas.gov.sg/former-ford-factory/whatson/exhibition-fall-of-sg/). Useful for relating military events to civilian experience and keeping the Battlebox conference distinct from the Ford Factory surrender.

All six source files also link to the publications on which they are based. Read the fuller originals before expanding an excerpt or attributing additional claims.

## Review checks for the first generated adventure

- Can a student explain the stage task and the intended recipient in one sentence?
- Does every essential conversation contribute to that task?
- Does showing a particular note produce a relevant new disclosure, challenge or changed response?
- Are reading questions grounded in the supplied passage, with a credible alternative interpretation?
- Are Japanese military effectiveness, Allied limitations and evidence of resistance all represented?
- Is a broader explanation distinguished from a claim about one person's motives or one decisive mistake?
- Are the first landings in Malaya distinguished from the later landings on Singapore Island?
- Are all later summaries and recollections labelled, with no historical character possessing hindsight?
- Does the final task ask for a supported explanation rather than choosing a source to exclude the others?

## Limits of this starter pack

This is a compact generation trial, not a complete textbook chapter or a historian-reviewed source reader. It contains no directly inspected Japanese operational orders or Japanese participant testimony. Sources A–D emphasise Allied institutions and later interpretations; Source F flags that imbalance without removing it. Do not invent a Yamashita conversation to compensate. An adventure focused closely on Japanese command decisions needs additional verified material.

Numbers of troops, prisoners, casualties, reservoir control and remaining supplies can vary with timing, definition and account. The adaptations deliberately avoid most precise totals. Do not turn the source descriptions of supply pressures into a new, exact countdown without further checking.
