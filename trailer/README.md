# Trailer

Concept trailer for Historical Adventures v3 (a Pocket Adventures title; Singapore, 1819), built with [Remotion](https://www.remotion.dev).
It is a standalone project, outside the npm workspaces, so it doesn't affect the app's builds or CI.

A short motivation (what history asks of students, and why reading and chatbots fall short), then numbered skill claims alternating with gameplay proof, then how easy creation is (drop in sources, we build it, press play; changes optional, in plain words), any episode, and the class summary: each claim card previews its game beat in a tilted window that
zooms to full screen. Game beats use a pixel town, in-game interface, realistic period documents and callouts. Cuts sit
on the music's beat grid.

```bash
cd trailer
npm install
npm run studio   # preview in the browser
npm run render   # writes renders/LATEST.mp4
```

Rendered videos live in `renders/`, which git ignores (they are 15-50 MB each): `LATEST.mp4` is the current cut, and
numbered files (`00-first-draft.mp4`, `01-draft.mp4`, ...) are earlier snapshots.

- Wording and episode content: `src/episode.ts`
- The cut (order, length in beats, transition): `CUT` in `src/Trailer.tsx`
- Game beats and pitch beats: `src/scenes.tsx`; pixel world: `src/pixel.tsx`; in-game interface: `src/hud.tsx`;
  period documents: `src/artefacts.tsx`; kinetic and typewriter pieces: `src/pitch.tsx`; creation: `src/creation.tsx`;
  transitions: `src/transitions.tsx`

The dialogue, notes, newspaper, memoir and letter are illustrative, written for the trailer, and marked as such on
screen. The publication and book titles are invented. The reveal's "what really happened" card summarises the
historical record.

## Audio
- **Music:** "Optimistic Corporate Technology" by RomanSenykMusic, from Pixabay (Pixabay Content License: free for
  commercial use, no attribution required). 80 BPM. Every cut sits on its eighth-note grid (0.375 s); the track starts
  so its first downbeat meets the first pitch card, and `fit` in `src/Trailer.tsx` removes whole bars (the breakdown)
  so the title card lands on the track's final downbeat. When the voiceover is on, the music ducks under it.
- **Voiceover:** currently **off** (`VOICEOVER` in `src/Trailer.tsx`). When on: OpenAI text-to-speech, read as one take
  and split per line (`scripts/make_voice.mjs`, see its header); line lengths in `src/voice.json` set the minimum length
  of each shot, and a human recording can replace the clips.
- **Sound effects** (whoosh, impact, typewriter, pop, chime): synthesised by `scripts/make_audio.py` (needs numpy). The
  script can also make a placeholder music bed, which is no longer used.
